# check

event type: `com.mbta.api-checker.check.v1`

Describes an instance of an [API Checker](https://github.com/mbta/api_checker/) check running and its result.

## Data

Fields in the event's `data`:

- `checkName` (string): The name of the check from the API Checker's configuration. E.g. `"heavy-rail-predictions-weekdays"`
- `success` (boolean): Whether or not the check succeeded.
